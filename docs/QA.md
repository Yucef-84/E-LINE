# 검증 기록

검증일: 2026-10-13 (Asia/Seoul)

## 빌드·리소스

- Node.js 22.16.0에서 `node scripts/check.mjs`, `node scripts/build.mjs` 성공.
- 20개 HTML ID와 내부 섹션 링크, 32개 로컬 리소스 확인.
- JavaScript 문법 검사 성공.
- 공개용 프로필·컴카드 PDF 생성 후 페이지 렌더링과 텍스트 추출로 새 이메일 및 개인정보 제외 확인.
- WebP 이미지 24개에 EXIF 메타데이터가 없음을 확인.
- 배포 폴더는 HTML/CSS/JS/이미지/폰트/다운로드 자료/검색 메타데이터만 포함.

## 브라우저

Codex 내장 Chromium 브라우저에서 `/E-LINE/` 경로로 검사했다.

- 데스크톱 첫 화면·갤러리·프로필·문의 화면 확인.
- 320px, 390px 모바일과 768px 태블릿 반응형 배치 확인.
- 모바일 메뉴 열기, Profile 선택 후 메뉴 닫힘 및 섹션 이동 확인.
- 스튜디오·일상·표정 필터별 4장, 전체 12장 표시 확인.
- 사진 확대, 다음 버튼, 방향키 이동, Esc 닫기 확인.
- 필터 적용 후 확대 화면이 해당 분야의 사진 4장을 대상으로 순환함을 확인.
- 이메일 복사 성공 상태 확인.
- 이메일, Instagram, 프로필·컴카드 링크 대상 확인.
- 페이지 내 로드된 이미지에 깨진 이미지 없음.
- 브라우저 콘솔 오류·경고 없음.

터치 스와이프는 구현되어 있으며 실제 모바일 기기의 제스처 검사는 별도다. OS 동작 줄이기는 CSS와 기능 초기화 분기에서 지원한다.

전화번호는 공개 HTML과 다운로드 문서에서 제외하고 이메일은 nedjma@steibu.com으로 통일했다. 기존 비공개 연락처가 포함된 원본 문서는 커밋에 포함하지 않는다.
