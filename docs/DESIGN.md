# E-LINE 홈페이지 기획·설계

## 목표와 방문자

키즈 모델 김일린의 표정과 촬영 적합성을 사진으로 보여주고, 캐스팅 담당자가 신체 정보와 활동 조건을 확인한 뒤 보호자에게 연락할 수 있게 한다. 주 방문자는 광고 제작사, 브랜드 담당자, 사진가, 캐스팅 담당자다.

## 콘텐츠 근거

제공된 `김일린-키즈모델-프로필.md`를 기본 정보의 기준으로 사용했다. 실제 사진은 `3돌 샘플`, `모델링 샘플`, `키즈노트 샘플`에서 선별했다. 웹용 이미지 출처는 `assets/images/manifest.json`에 기록했다.

2023년생 여아, 키즈 모델·아동 연기, 서울·경기와 주말 중심의 활동 조건, 키 97cm·몸무게 15kg·의류 100·신발 150을 표시한다. 생년 기반 표기로 시간이 지나면 틀려지는 개월 수 표기를 피한다. 현재 신체 정보와 일정은 섭외 시 확인하도록 안내한다.

낯가림이 적음, 일상 대화와 촬영 지시 수행, 활동성, 다양한 표정, 자연스러운 근접 촬영 시선, 생활형 콘텐츠 집중력을 캐스팅 문구의 근거로 삼는다. Korean–Algerian background와 알제리 아랍어 듣기·간단한 단어 말하기 수준은 제공 문서 그대로 반영한다. 확인되지 않은 경력이나 협업 실적을 만들지 않는다.

## 레퍼런스 적용

참고 화면: [Lightspark — Godly](https://godly.design/website/lightspark/), [첫 화면](https://cdn.godly.design/sites/lightspark/hero-desktop.webp), [전체 화면](https://cdn.godly.design/sites/lightspark/desktop-full.webp).

중앙에 큰 문장과 짧은 설명, 작은 CTA를 놓고 주변을 이미지가 감싸는 구성을 적용한다. 금융 UI 대신 실제 모델 사진을 종이 사진처럼 배치한다. 이미지는 식별 가능한 선명도를 유지하고, 사진 바깥에만 은은한 색 번짐을 둔다. 이후 넓은 여백과 가는 구분선, 번호가 있는 섹션으로 내용을 이어가고, 마지막은 어두운 배경과 큰 이름으로 마무리한다.

## 정보 구조와 행동

1. **Hero**: “작은 순간, 큰 가능성.”과 대표 사진. 포트폴리오 또는 문의로 이동.
2. **About**: 이름, 자연스러운 표현 강점, 출생 연도, 활동 지역과 일정, 배경.
3. **Selected moments**: 실제 사진 12장. 전체/스튜디오/일상/표정 필터. 확대 사진은 현재 필터 내에서 순환.
4. **A good fit**: 키즈 패션·피팅, 라이프스타일·식품, 완구·교육, 영상 광고·아동 연기의 적합성을 설명.
5. **Model profile**: 네 가지 사이즈를 큰 숫자로 표시하고 언어·촬영 강점·활동 조건을 표로 제공. 공개용 PDF/JPG 다운로드.
6. **Contact**: 보호자에게 직접 연락. 이메일 앱, Instagram 링크, 이메일 복사.
7. **Footer**: 모델명과 Instagram, 맨 위로 이동.

문의 폼과 서버를 만들지 않고, 실제 보호자 연락 수단으로 연결한다. 연락처 입력·저장·수집이 발생하지 않는다.

## 구현과 운영

HTML/CSS/JavaScript로 구현한다. 프레임워크와 외부 런타임 의존성 없이 정적 호스팅에서 동작한다. 사진과 폰트도 동일 사이트에서 제공한다. Node 빌드는 배포 파일만 `dist/`에 복사한다. GitHub Actions로 빌드 검증 후 GitHub Pages에 배포한다.

키보드 초점 표시, 본문 건너뛰기, 사진 대체 설명, 필터 상태 읽기, native dialog의 초점 제한과 닫은 뒤 초점 복원, 모바일 메뉴의 inert 상태를 지원한다. OS의 동작 줄이기 설정에서는 부유·등장·부드러운 스크롤을 제거한다. 작은 화면에서는 사진이 중앙 문장과 겹치지 않도록 별도 위치를 적용한다.

WebP 640px/1200px 버전, 갤러리 지연 로딩, 상대 경로, 로컬 웹폰트, OG 이미지와 ProfilePage 구조화 데이터를 사용한다. 원본 사진을 수정하지 않고 EXIF 없는 웹용 버전으로 배포한다. 프로필과 컴카드는 공개용 문서로 새로 제작한다. 개인 전화번호와 이전 이메일은 문서 및 홈페이지에서 제외하고, 공개 이메일 nedjma@steibu.com과 Instagram만 제공한다.

## 수용 기준

- 제공 프로필 정보와 연락처가 정확하고 실제 사진을 사용한다.
- PC와 모바일에서 중앙 문장·사진·메뉴가 겹치지 않는다.
- 갤러리 필터별 4장, 전체 12장으로 표시된다.
- 확대 사진의 이전·다음·방향키·Esc·터치 이동이 동작한다.
- 파일 다운로드, 이메일·Instagram 링크가 올바른 대상을 가리킨다.
- JavaScript 오류 및 누락된 리소스가 없고 사이트 하위 경로에서도 동작한다.
- 동작 줄이기 및 키보드 내비게이션을 지원한다.
